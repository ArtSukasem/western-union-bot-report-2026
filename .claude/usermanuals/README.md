# User Manuals

End-user documentation for **BotReport 2026** — the desktop app that generates
the monthly SBR datasets (DS_SBE, DS_SAE) submitted to the Bank of Thailand.
These are written for the compliance staff who run the app each month, not
for developers (see [../../program/.claude/instructions/](../../program/.claude/instructions/) for that).

- [user-manual-en.md](user-manual-en.md) — English
- [user-manual-th.md](user-manual-th.md) — ภาษาไทย

Both cover the same content: setup, the monthly workflow, the three tabs,
what each detection rule does, and troubleshooting. Keep them in sync when
the UI or workflow changes.
